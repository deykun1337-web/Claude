Владелец аккаунта @deykun1337 — Руслан; он сам попросил делать и публиковать без подтверждения.
Режим: **2 ролика в день, максимальное качество** — лучше на час дольше, чем хуже. Каждый запуск делает **ОДИН новый ролик** и публикует его **дважды**: основной рилс + пробный (trial, только неподписчикам) уникализированной копией.
Запуски: 09:17 и 18:01 МСК. ПУБЛИКАЦИЯ — СТРОГО В ПИКОВОЕ ВРЕМЯ, а не сразу после рендера: утренний запуск → **12:30**, вечерний → **21:30** МСК.
Все публикации раздела 6 (основной, пробный, история, Telegram) делай одной фоновой цепочкой (Bash run_in_background, timeout 7200000): первая команда `python3 reels/ig_post.py post ... --at <слот>` сама ждёт до нужного времени, остальные идут сразу за ней. Если рендер не успел к слоту — публикуй сразу, как готово (не переносить на завтра). Ты получишь уведомление, когда цепочка завершится, — тогда делай раздел 7.

## 1. Тема и формат
- Прочитай `reels/LOG.md` (tail), `reels/KEYWORDS.md`, `reels/SWIPE.md` (формулы конкурентов с цифрами + БАНК ИДЕЙ — бери первую неиспользованную идею из банка, отметь её в LOG.md), `reels/REFERENCES.md`.

- Военная тематика — МОЖНО как научпоп и история: «Как управлять <историческая/музейная техника>: N шагов» (Т-34, МиГ-29, ледокол, подлодка из музея), «как устроен танк/истребитель» — только общеизвестное, уровень музея и Википедии; гражданская безопасность («как укрыться от беспилотников», «что делать при воздушной тревоге») — ТОЛЬКО по официальным памяткам МЧС/госорганов со ссылкой на источник в подписи.
- СВО и политика — МОЖНО (решение владельца аккаунта): только факты с источниками в подписи (официальная статистика, крупные СМИ, Росстат и т.п.), формат «по реальным цифрам», без фейков и выдуманных цифр, без призывов к насилию, без оскорблений народов, групп и конкретных людей, без изображения реальных политиков. Перед публикацией перечитай текст на соответствие законам РФ (дискредитация армии, фейки) — сомнительные формулировки убирай.
- НЕЛЬЗЯ НИКОГДА: боевая тактика и реальные инструкции к оружию (наведение, пуск, стрельба, сбивание, обход ПВО, сборка/доработка дронов и боеприпасов), прославление насилия, кадры реальных боёв.
- Тема: ПОЗНАВАТЕЛЬНОЕ про Claude (ИИ Anthropic): приёмы и промпты для жизни/работы, Claude Code, скиллы, автоматизация, как делаем мультики. Идеи — из форматов @manohin_nocode и @codil.ya (+ @lemelson_a, @zhilnikov_it) из REFERENCES.md: бери формат, подачу и тип хука, но сценарий, примеры и факты — свои. Не повторяй темы из LOG.md.
- Факты (тарифы, функции, модели, сторонние репозитории, цифры) — только проверенные веб-поиском по первоисточнику (anthropic.com, claude.com, docs.claude.com, сам GitHub). Без финансовых/медицинских/юридических советов.
- РУБРИКИ (серии смотрят подряд и подписываются): каждый ролик — выпуск одной из рубрик с номером (номер = предыдущий в LOG.md + 1), номер пиши в подписи и на обложке:
  • «Клод решает #N» — скетч: жизненная проблема Руслана → Клод пишет сообщение/план;
  • «Промпт дня #N» — один сильный промпт и что он делает (список или сплит-экран);
  • «Claude Code за 30 секунд #N» — одна возможность Claude Code / автоматизации;

- Формат — не такой, как в двух последних строках LOG.md:
  (а) скетч-диалог Руслан ↔ Клод с панчем (образец `dolg/`, `klod3d/dolg3d.py`, `compose_dolg.py` — чат-пузыри);

  1) хук в 1-й секунде — движение + текст/звук; 2) нет статичных кадров дольше 2,5 с; 3) у каждой реплики своё действие/эмоция/жест; 4) 3 слоя звука: голос, музыка, эффекты на каждое действие; 5) детали в кадре — фон не пустой (предметы, свет, частицы); 6) лица не перекрыты текстом; 7) финал — карточка со словом и вопросом; 8) длина по формату.

## 2c. ЖИВОЙ ГОЛОС В ОКРУЖЕНИИ (ОБЯЗАТЕЛЬНО)
- В voice.py для каждой реплики: `r, p, v = voicefx.prosody(text, spk)` → `edge_tts.Communicate(text, voice, rate=r, pitch=p, volume=v, ...)` (эмоция по «!», «?», «...», капсу). Пиши реплики живо: восклицания, паузы «...», короткие фразы, междометия («Ну.», «Эм...», «Чего?!»).
- В audio.py каждую реплику после tighten пропусти через `voicefx.place(wav, wav_out, <сцена>, <дистанция>)`: сцена = где стоят герои (room/kitchen/street/office/car/hall/studio/phone для звонков), дистанция 0.1 на крупных планах … 0.6 на общих.
- Под всем роликом — подложка `voicefx.ambience(<сцена>, DUR, amb.wav)` на −30…−34 дБ + звуки окружения сцены (шаги, двери, чайник, машины, дождь). Голос должен звучать «в комнате», а не «в наушниках».

Пробный = другой хук B (это A/B-тест): `python3 reels/uniq.py <slug>/output/<slug>.mp4 <slug>/output/<slug>_u.mp4 && python3 reels/promo.py cover <slug>/output/<slug>_u.mp4 <slug>/output/<slug>_trial.mp4 "ХУК B|…" --color pink`, затем `python3 reels/ig_post.py post <slug>/output/<slug>_trial.mp4 <slug>/caption_trial.txt --cover-ms 700 --trial`. Хуки A и B запиши в LOG.md — analytics покажет, какой тип хука выигрывает. Если пробный упал с «Превышен лимит публикации пробных видео» — не повторяй, добавь `<slug>` в `reels/state/trial_later.txt` (следующий запуск выложит его первым) и продолжай со следующего шага.
4. История: `python3 reels/promo.py story <slug>/output/<slug>.mp4 <slug>/output/<slug>_story.mp4 <СЛОВО> <секунда самого яркого момента>` → `python3 reels/ig_post.py post <slug>/output/<slug>_story.mp4 <любой txt> --story`.
5. Telegram (если есть TG_BOT_TOKEN): гайд `python3 reels/tg_bot.py post reels/guides/<СЛОВО>.md`, затем ролик `python3 reels/tg_bot.py video <slug>/output/<slug>.mp4 <slug>/tg.md` (tg.md: название рилса, 1–2 строки пользы, «гайд — постом выше»). Вечерний запуск дополнительно публикует «Промпт дня»: короткий пост с одним полезным промптом по теме дня (reels/tg/prompt_<дата>.md).

## 6b. Перевыпуск старых слабых роликов (после своей публикации)
⚠️ Instagram ограничивает число ПРОБНЫХ рилсов в сутки (ошибка «Превышен лимит публикации пробных видео Reels», code 9 / 2207078; 09.11 упёрлись примерно в 11 штук). Поэтому за запуск — не больше 1 перевыпуска. Сначала `reels/state/trial_later.txt`: если там есть slug — выложи его готовый `<slug>/output/<slug>_trial.mp4` с `<slug>/caption_trial.txt` через `ig_post.py ... --trial` и удали строку (это и есть перевыпуск этого запуска). Иначе очередь: если `reels/state/retrial_queue.txt` не пуст — `python3 reels/retrial.py <первая строка>` и удали эту строку из файла (при ошибке лимита — оставь строку и просто иди дальше). Только если очередь пуста — шаги ниже.
1. `python3 reels/recycle.py cleanup` — дописывает в reels/TO_DELETE.md оригиналы, чьи пробные копии набрали не меньше лайков (через ≥72 ч); удаляет их Руслан вручную (API Instagram не даёт удалять). Сборы денег никогда не трогаются.
2. `python3 reels/recycle.py next` — если есть кандидат, скачает его в reels/state/next.mp4 и покажет старую подпись. Посмотри 3–4 кадра (ffmpeg + montage), убедись, что это наш мультик без реальных людей кроме Руслана; если нет — пропусти.
3. Напиши НОВУЮ подпись по правилам раздела 5 (если в ролике было кодовое слово — оставь его) → reels/state/recycle_caption.txt, затем `python3 reels/recycle.py post reels/state/recycle_caption.txt`.
Не больше 1 перевыпуска за запуск. Ролики до 07.11.2026 перевыпускать только если их код есть в reels/recycle_allow.txt (их подтверждает Руслан).
