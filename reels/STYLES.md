# Фирменные стили роликов — премиум, ЧЕРЕДОВАТЬ

**Выбор стиля — автоматически:** `python3 reels/style_pick.py <am|pm> "<тема>"` → используй ровно этот стиль.
После публикации: `python3 reels/style_pick.py log <номер> <slug>` (история в reels/state/styles_used.txt).
Правила пикера: стиль не повторяется ни с одним из 3 последних роликов; в день **1 ролик UI-моушн (3/4/9)** — именно такие
форматы залетают в нише Claude (ИИмерсивный, dino81club, manohin) — и **1 ролик с персонажами** (1/2/5/6/7/8).

Герои во всех стилях одни и те же: **Клод — КАБАН** (лососево-красный, пятачок, клыки, искорка Claude; в UI-стилях — пиксельный
кабан-маскот `M.boar()`), **Руслан** — розовая кепка DEYKUN, белая футболка, золотая цепь, джинсы.

## Общий премиум-стандарт (для ВСЕХ стилей, проверять перед публикацией)
1. Хук в 1-й секунде: крупный текст-вопрос/число + движение (не статичный кадр).
2. Смена визуала каждые 1,5–2,5 с: новый элемент, наезд камеры, переход. Ничего не стоит дольше 2,5 с.
3. Каждый элемент **появляется анимацией** (подъём + проявление 0,35 с, «пружина» для акцентов) и **уходит** мягко.
4. Типографика: Inter 600–900, максимум 2 строки, ключевые слова акцентным цветом (`*слово*`), моно-шрифт для кода/меток.
5. Глубина: мягкие многослойные тени, свечение, виньетка, медленная камера (`M.camera`), параллакс фона.
6. Звук: свой бит (reels/music.py) + звуки на каждое появление (щелчок, свуш, «тук» на числах) + живой голос.
7. Субтитры фразами (`U.phrase_captions`) — в UI-стилях роль субтитров играет `M.headline` (не дублировать).
8. Финал 2,5–3 с: строка комментария со СЛОВОМ (`M.keyword_bar`) + карточка Telegram (`M.tg_card`) или `U.endcard`.
9. 1080×1920, 30 fps, без чужих логотипов в кадре (Anthropic/Claude можно только текстом), без чужих треков.

### 3 — Тёмный редакционный (рецепт сцены)
Фон `M.bg(M.DARK, t)` — почти чёрный, тёплое оранжевое свечение «дышит» и сдвигается к активному элементу (`glow_at`).
Сверху моно-метка раздела `M.label(th, "5 скиллов")`. Фраза по центру `M.headline(th, t, t0, "Один *сканирует*…")` — слова
проявляются по одному. Элементы: карточка репо (`M.card(..., glow=True)`) + штамп `M.stamp("БЕСПЛАТНО")`, ряд плиток-иконок
`M.tiles(...)` с подсвеченной активной, свечи графика `M.candles`, большое число `M.big_number` (отсчёт), окно чата Claude
`M.chat(...)` с «печатает…», финал `M.tg_card` + `M.keyword_bar`. Камера медленно наезжает 1.0→1.06 на каждую сцену.

### 4 — Светлый «бумага + точки» (рецепт сцены)
Фон `M.bg(M.LIGHT, t)` — тёплая бумага с точечной сеткой (дрейф). Тёмные окна кода `M.window` + `M.code(..., hi={строка: красный})`
печатаются посимвольно, курсор «ты» `M.cursor` двигается по `M.move(t, путь)` и кликает (рябь). Нумерованные карточки шагов
`M.step(n, title, body, dark=чередовать)` со стрелками `M.arrow`, кольцо прогресса `M.ring`, терминал Claude Code `M.terminal`.
Пиксельный кабан `M.boar()` живёт в каждой сцене (подпрыгивает, «бегает» между карточками). Камера: наезды на активную карточку.
