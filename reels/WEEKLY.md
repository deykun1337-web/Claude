# Еженедельный отчёт (запускается задачей; модель — экономная)

1. `git pull`; `python3 reels/analytics.py` (обновит ANALYTICS.md).
2. Цифры сейчас: подписчики Instagram (`GET /17841409120122863?fields=followers_count`), участники Telegram (`python3 - ` с getChatMemberCount для chat_id из reels/state/tg.json, токен в $TG_BOT_TOKEN), сравни с reels/state/baseline.json → прирост за неделю.
3. Из LOG.md за неделю: сколько роликов вышло, какие кодовые слова; из reels/state/ig.json: сколько людей получили гайд/ссылку.
4. Топ-3 и анти-топ-3 роликов недели (ANALYTICS.md) → 3 вывода: какие формат/хук/тема тянут подписчиков.
5. Обнови банк идей в reels/SWIPE.md: подними наверх идеи в формате победителей, убери похожие на проигравших.
6. Запиши отчёт в reels/reports/<дата>.md, обнови baseline.json текущими цифрами, закоммить и запушь.
7. Итог (5–8 строк для Руслана): прирост Instagram и Telegram, лучший ролик, что меняем на следующую неделю.
