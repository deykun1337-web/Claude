# Автоответ по кодовому слову (только подписчикам)

Схема: человек пишет КОДОВОЕ СЛОВО под рилсом → бот отвечает в комментарии «отправил в Директ» → в Директе просит подписаться → проверяет подписку → присылает гайд.

Делается в **ManyChat** — официальный партнёр Meta, работает через Instagram API, пароль от аккаунта никому не передаётся. Свой сервер для этого не нужен.

## Один раз
1. Instagram @deykun1337 должен быть профессиональным аккаунтом (Автор или Бизнес).
2. В Instagram: Настройки → Сообщения и ответы на истории → Управление сообщениями → Подключённые инструменты → **Разрешить доступ к сообщениям** — включить.
3. manychat.com → Get started → Instagram → войти через Instagram и подключить @deykun1337.
4. Бесплатного тарифа хватает для старта. Если ManyChat попросит Pro для условия «подписан ли» или когда контактов станет много — включить Pro.

## Для каждого рилса (≈5 минут)
1. Automation → New Automation → шаблон **«Auto-DM links from comments»** (или пустой сценарий).
2. Триггер: **User comments on your Post or Reel** → выбрать рилс → *Specific keywords* → кодовое слово (например `ДОЛГ`, плюс варианты `долг`, `Долг`).
3. **Public reply** (ответ в комментарии, 3 варианта по очереди): «Отправил в Директ 📩», «Лови в сообщениях 👀», «Готово, проверь Директ ✅».
4. Первое сообщение в Директ: «Привет! 👋 Гайд пришлю сразу — только подпишись на @deykun1337 и нажми кнопку ниже». Кнопка: **«Я подписался ✅»**.
5. По нажатию кнопки — блок **Condition → «Is following your account» / «Подписан на вас»**:
   - **Да** → сообщение с гайдом (текст из `reels/KEYWORDS.md` + ссылка на гайд).
   - **Нет** → «Пока не вижу подписку 🙈 Подпишись на @deykun1337 и нажми ещё раз» + та же кнопка (ведёт снова на проверку).
6. Включить сценарий (Set Live). Проверить со второго аккаунта: написать слово под рилсом.

## Где хранить гайд
- Проще всего: **telegra.ph** — вставить текст из `reels/guides/<СЛОВО>.md`, нажать Publish, ссылку вставить в сообщение из шага 5.
- Или прислать короткий гайд прямо текстом в Директ (до ~1000 символов).

## Важно
- Instagram разрешает первое сообщение комментатору только одно; дальше переписка открывается, когда человек нажимает кнопку. Поэтому кнопка «Я подписался» обязательна.
- Не делать больше сотен автоответов в час и не слать ссылки на сторонние «серые» сайты — Instagram может ограничить аккаунт.
