# Почему лимит Claude кончается так быстро — и что делать (гайд @deykun1337)

Главное: в каждом новом сообщении Claude заново обрабатывает всю переписку в этом чате. Чем длиннее чат и чем больше в нём файлов, тем дороже каждое следующее сообщение — лимит тает всё быстрее.

## 5 привычек, которые экономят лимит
1. **Новая задача — новый чат.** В Claude Code — команда `/clear` (или `/compact`, чтобы сжать историю и продолжить).
2. **Все вопросы — одним сообщением.** Не «а ещё…» пятью сообщениями, а один список.
3. **Постоянные файлы — в Проект.** Инструкции, тексты, документы, которые нужны каждый раз, клади в знания Проекта, а не загружай в каждый чат заново.
4. **Простое — моделям попроще.** Переписать абзац или придумать заголовок можно на более лёгкой модели, тяжёлую оставь для сложного.
5. **Следи за расходом:** Настройки → Использование, в Claude Code — `/usage`.

## Готовые фразы
- «Сделай краткое резюме нашего чата в 10 строк — я начну новый чат с ним».
- «Ответь на все вопросы ниже по порядку, коротко: 1)… 2)… 3)…»
- «Отвечай без вступлений и повторов вопроса».
