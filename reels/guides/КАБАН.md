# Как начать делать мультики с Claude (гайд @deykun1337)

## Что нужно
1. **Платная подписка Claude** с доступом к Claude Code (актуальные тарифы — на claude.com/pricing).
2. **Claude Code в облаке** — claude.ai/code или приложение Claude: открываешь сессию, подключаешь свой репозиторий GitHub. Ничего не ставишь на компьютер, можно с телефона.
3. **Blender** — бесплатная 3D-программа. Claude сам ставит её в облачную среду и пишет сцены кодом на Python.
4. **Голоса** — нейросетевой синтез речи (например, edge-tts с русскими голосами), а Claude подкручивает тембр: бас, писк, эхо.
5. **Идея одной строкой** или ссылка на рилс, формат которого нравится.

## Первый запуск (по шагам)
1. Создай пустой репозиторий на GitHub и открой его в Claude Code.
2. Попроси: «Настрой облачную среду для мультиков: ffmpeg, Blender, Python (pillow, cairosvg, numpy), нейроголос на русском. Сначала покажи план».
3. Первый ролик: «Сделай мультик 15 секунд, 9:16, блочный 3D. Герой — [персонаж]. Сюжет: [идея]. Озвучка, субтитры, водяной знак @[ник]».
4. Смотри кадры и правь словами: «камера ближе», «текст налезает на лицо», «больше движения».

## Промпты, которые экономят время
- «Перед рендером покажи 6 контрольных кадров одной картинкой».
- «Держи 3 варианта каждой реплики для озвучки — сервис иногда падает».
- «Сделай петлю: последний кадр переходит в первый».
- «Посмотри этот рилс [ссылка] и сделай такой же формат, но со своим сценарием».

Рендер 30-секундного 3D-ролика в облаке — от 30 минут до пары часов, это нормально.
