# Как создать своего агента в Claude Code (гайд @deykun1337)

Субагент — это отдельный «помощник» внутри Claude Code: у него своя роль, свой набор инструментов и **своё чистое окно контекста**. Главный Claude отдаёт ему задачу и получает готовый результат, не засоряя основной чат. Несколько агентов могут работать параллельно.

## Способ 1 — через меню (проще всего)
1. Открой Claude Code (claude.ai/code, приложение Claude или терминал).
2. Набери команду `/agents` → «Create new agent».
3. Выбери, где он будет жить: в проекте (виден всем в репозитории) или личный (во всех твоих проектах).
4. Опиши словами, что он делает — Claude сам сгенерирует описание и инструкции. Поправь и сохрани.

## Способ 2 — файлом
Создай файл `.claude/agents/scout.md` в своём проекте:

```
---
name: scout
description: Ищет залетевшие рилсы в нише и сравнивает просмотры со средними по аккаунту
tools: WebSearch, WebFetch, Read
model: haiku
---
Ты разведчик. Найди 10 рилсов, которые набрали в 3+ раза больше
просмотров, чем обычно у этого автора. Для каждого: ссылка, хук первой
секунды, формат, почему залетел. Ответ — таблица.
```

- `description` — самое важное: по нему Claude понимает, когда звать агента.
- `tools` — можно не писать, тогда агент получит те же инструменты, что и основной чат.
- `model` — `haiku` для простой рутины (дёшево и быстро), `sonnet`/`opus` для сложного.

## Как запускать
- Просто попроси: «Используй агента scout и найди идеи для рилса про Claude».
- Или дай большую задачу — Claude сам раздаст части подходящим агентам.
- Несколько сразу: «Запусти параллельно scout, writer и checker».

## Наша команда из ролика
scout (ищет залёты) → writer (сценарий) → editor (рендер и монтаж) → checker (проверка: субтитры, звук, кодовое слово) → publisher (публикация и ответы). Начни с одного агента под свою самую нудную задачу.
