# Как ничего не потерять в Claude Code (шпаргалка @deykun1337)

## 1. Откат к любому моменту
Нажми **Esc два раза** или набери `/rewind` — выбери своё сообщение, и Claude Code вернёт код и/или разговор к тому моменту. Это работает для правок файлов, которые делал сам Claude.

## 2. Команды в терминале откат не видит — спасает git
Если файл удалён командой в терминале (например, `rm`), `/rewind` его не вернёт. Поэтому:
- в начале работы: «Сделай git init и первый коммит, если репозитория ещё нет»;
- перед большими правками: «Закоммить текущее состояние с понятным сообщением»;
- вернуть файл: «Восстанови файл X из последнего коммита».

## 3. Ручной режим разрешений
Пусть Claude спрашивает перед запуском команд и правками — это режим по умолчанию. Переключение режимов — Shift+Tab. Не включай «разрешить всё» в важных проектах.
