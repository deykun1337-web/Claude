# Шпаргалка: команды Claude Code (от @deykun1337)

## 5 команд из ролика
- `/init` — Claude изучит проект и создаст CLAUDE.md: правила и описание проекта, которые он читает в каждой сессии.
- `/clear` — очистить разговор: новая задача, чистый контекст, лимит тратится медленнее.
- `/compact` — сжать длинную переписку в краткое резюме и продолжить работу.
- `Esc` `Esc` (или `/rewind`) — откат к любому твоему сообщению: вернуть код и/или разговор.
- `Shift+Tab` — переключить режим: спрашивать разрешение / принимать правки самому / режим плана.

## Ещё полезное
- `/model` — выбрать модель (тяжёлую для сложного, лёгкую для простого).
- `/resume` — вернуться к прошлому разговору.
- `/memory` — открыть и поправить CLAUDE.md.
- `/agents` — создать и настроить своих субагентов.
- `/mcp` — подключённые MCP-серверы и инструменты.
- `/permissions` — что Claude можно делать без вопросов.
- `/help` — список всех команд.
- `@файл` в сообщении — дать Claude конкретный файл.
- `!команда` — выполнить команду терминала прямо из чата.
