# SWIPE · 30 рилсов · @manohin_nocode (116k, медиана 13.2k) + @codil.ya (10k, медиана 13.6k) · база: медиана автора

Выборка годная: 15+15 рилсов с медианой. Сигнал = во сколько раз ролик обогнал свою норму (>3x — уже сигнал, здесь все 8–600x).
Англоязычный классификатор ig-viral русские хуки не размечает — формулы ниже выделены вручную.
⛔ Военные/политические темы (СВО, С-300, танки, Су-27, беспилотники) — в выборке самые большие, но мы их НЕ берём (правила канала).

## Формулы, которые выстрелили
| формула | примеры (×медиана) | почему работает |
|---|---|---|
| **«Как управлять <сложная машина>: N шагов»** — симулятор профессии, серия с «Дальше: …» | танк 144x, Су-27 114x, беспилотник 32x | любопытство + «я тоже смогу», серия держит подписку |
| **«Клод. Я <катастрофа>.»** — 2–5 слов, ИИ-авария | «Я удалил базу» 129x, «рыбачил 3 дня — 500 заказов» 37x | мгновенный конфликт, узнаваемая боль |
| **«Claude Code сделал X без спроса???»** — агент своевольничает | «заказал Лавку» 91x | абсурд + реальная фича (агентность) |
| **Туториал в скетче** | «установка Claude Code» 91x | польза + сохранения |
| **«Что, если каждый <X> в 2 раза <сильнее>»** — эскалация | 83x | нарастание, досматривают до конца |
| **Провокация-утверждение** | «Claude Code похоронит вашу жизнь» 49x | спор в комментариях |
| **Холодный старт без текста + звук** | «Дзынь! +500 ₽» 54x, «…приложение» 49x | первые 1–2 с без слов, интрига |
| **Нейросети-персонажи / вайбкодеры, сериал «Серия N»** | «три типа вайбкодеров» 18x, «Война вайбкодеров», «у костра» 15x | мир с героями, ждут продолжения |

Общее у топа: хук ≤ 7 слов или вообще без слов; длина 35–175 с (длинные симуляторы держат); CTA почти всегда «гайд в шапке / Telegram», у нас — **КОДОВОЕ СЛОВО в комментариях (обязательно)**.

## Банк идей (наши версии → каждая с кодовым словом и гайдом)
1. **«Как управлять Боингом 737: 6 шагов из кабины»** — Клод-инструктор, Руслан за штурвалом; серия «Дальше: поезд метро / ледокол / МКС». Слово **ПИЛОТ** → гайд «Промпт-тренажёр: Claude объясняет любую профессию по шагам».
2. **«Клод. Я удалил папку с проектом.»** → спокойный Клод: «Git помнит всё». Слово **БЭКАП** → гайд «Как работать с Claude Code и ничего не потерять: git, бэкапы, режимы подтверждения».
3. **«Claude Code сам записал меня к стоматологу???»** — агент сделал «как лучше». Слово **АГЕНТ** → гайд «Что Claude Code может делать сам, а что только с разрешения».
4. **«Клод, я неделю спал. Почему у меня 21 новый рилс?»** — наш комбайн (правда). Слово **КОМБАЙН** → гайд «Как устроен автопостинг: Claude делает рилсы каждый день».
5. **«Туториал: ставим Claude Code за 60 секунд»** в виде скетча. Слово **УСТАНОВКА** → пошаговый гайд (проверить по docs.claude.com).
6. **Холодный старт: «Дзынь!» — уведомление «+1 клиент», Клод молча допивает кофе** → объяснение, какой промпт это сделал. Слово **КЛИЕНТ** → гайд «3 промпта для заявок и ответов клиентам».
7. **«Что, если каждое „сделай красиво“ делает дизайн в 2 раза пафоснее?»** — эскалация до абсурда. Слово **ДИЗАЙН** → гайд «Как правильно просить дизайн у нейросети».
8. **Сериал «Нейросети в одном офисе», Серия 1…** — Клод-кабан и коллеги-нейросети (без чужих логотипов и имён компаний на персонажах). Слово **СЕРИАЛ** → ранний доступ к следующей серии в Telegram.
9. **Провокация: «Claude заменит тебе 3 приложения»** + список. Слово **ЗАМЕНА** → гайд-список.
